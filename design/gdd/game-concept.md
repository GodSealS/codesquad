## Elevator Pitch

> **它是一个「玩家创造地牢」的 3D 动作角色扮演游戏——你既是冒险者，也是地下城主。用模板化工具设计属于你自己的地牢，发布给全世界挑战；然后扮演冒险者闯入别人的作品，体验永无止境的新内容。**

## Core Fantasy

> **你是一个走过无数战场的传奇冒险者。如今你退居幕后，成为一名试炼师——你用自己亲身经历过的战斗和考验，为新一代冒险者打造挑战。你不是英雄了，你是制造英雄的人。**

这个核心幻想的独特之处：
- **创造与消费的闭环**：你的"冒险经历"变成了地牢素材，别人的攻略反馈又成为你新的成长动力
- **从学徒到大师的弧线**：一开始你闯别人的地牢学习，后来你积累经验创造自己的作品，最终你的名字被挂在排行榜上
- **每一次登录都是新的**：没有固定的主线剧情——内容池永远在增长，永远有新东西可玩

---

## Unique Hook

> **它就像《马里奥制造》，但 And Also 是一场 3D 动作 RPG——你用模板化工具亲手设计地牢的每一个房间，然后作为冒险者亲自打穿它。从"做出一个地牢"到"别人挑战我的地牢"，整个过程就是游戏的全部。**

## Player Experience Analysis（MDA Framework）

### Target Aesthetics（What the Player FEELS）

| Aesthetic | Priority | How We Deliver It |
|-----------|:--------:|-------------------|
| **Expression**（自我表达、创造力） | 1 | UGC 编辑器是核心玩法——每个地牢都是作者个性的延伸 |
| **Challenge**（挑战、掌握） | 2 | 玩家创作的地牢天然需要技巧和策略才能通关 |
| **Discovery**（探索、发现） | 3 | 每一次冒险都是全新内容——从建筑布局到怪物配置都是新谜题 |
| **Fantasy**（幻想、角色扮演） | 4 | "退隐冒险者化身试炼师"的角色弧线 |
| **Fellowship**（社交连接） | 5 | 异步社交——发布作品、挑战好友、评分反馈 |
| **Sensation**（感官愉悦） | 6 | 战斗手感、视觉反馈、特效 |
| **Narrative**（故事、戏剧） | 7 | 故事是战斗的"佐料"不是主菜（反支柱 D） |
| **Submission**（放松、舒适） | N/A | 本作不主打放松体验 |

### Key Dynamics（Emergent Player Behaviors）

我们希望通过系统设计自然涌现的玩家行为：

1. **展示欲**：做完地牢后迫不及待地发布，邀请别人来挑战
2. **攀比心**：看到别人高质量的作品后，激发"我也要做更好的"的动力
3. **迭代创作**：收到反馈后反复修改打磨自己的作品
4. **探索欲**：浏览新发布列表，总想"再试一局别人的地牢"
5. **社区标准形成**：社区自然地形成好地牢的标准（玩法设计>堆怪>画面精美度）

### Core Mechanics（Systems We Build）

1. **3D 动作战斗系统**：第三人称、近战连击 + 远程射击 + 元素效果（火/冰/雷），基于 Godot StateMachine 实现
2. **模板化 UGC 地牢编辑器**：EditorPlugin 插件，在 3D 视口中拖放房间/怪物/道具/出口
3. **地牢发布与消费系统**：上传 DynamoDB → 列表浏览 → 下载游玩 → 评分反馈
4. **角色成长系统**：等级提升 → 攻击力/血量增长 → 解锁更多编辑组件
5. **异步社交系统**：玩家档案、作品集、点赞/收藏、排行榜

## Player Motivation Profile

### Primary Psychological Needs Served

| Need | How This Game Satisfies It | Strength |
|------|---------------------------|:--------:|
| **Autonomy**（自由、有意义的选择） | 自由决定玩什么——自己创作 or 挑战别人；创作时自由度由"模板化组件"定义 | Core |
| **Competence**（掌握、技能成长） | 战斗技巧提升 + 创作水平提升，两条成长曲线并行 | Core |
| **Relatedness**（连接、归属） | 通过作品展示与反馈建立异步社交连接——你的创造力被看到、被认可 | Supporting |

### Player Type Appeal（Bartle Taxonomy）

| Type | How This Game Serves Them |
|:----:|--------------------------|
| 🟢 **Achievers**（成就者） | 等级成长、地牢发布数量、评分累计、排行榜排名——始终有可量化的目标 |
| 🟢 **Explorers**（探索者） | 别人的地牢就是无尽的探索内容——每次进入都是全新的布局和挑战 |
| 🟡 **Socializers**（社交者） | 异步社交——通过作品交流、点赞评论、通过好友作品集互相了解 |
| 🟡 **Killers**（竞争者） | 排行榜竞争——谁的 Boss 最难？谁的通关时间最短？ |

### Flow State Design

| Dimension | Approach |
|-----------|----------|
| **Onboarding** | 第一个地牢由系统提供（预设教学关）→ 教会基础操作后引导进入编辑器→制作最简单的战斗房 |
| **Difficulty Scaling** | 玩家创作内容天然形成难度梯度——差的作品易通过，好的作品有挑战。系统提供难度标签帮助选择 |
| **Feedback Clarity** | 战斗：命中反馈（HitStop、粒子、音效、伤害数字）。创作：WYSIWYG 即时预览 |
| **Recovery from Failure** | 死亡后从地牢起点重新开始（不损失装备/等级），但评级会受影响。没有永久死亡惩罚 |

## Core Loop

### Moment-to-Moment（微循环 — 30秒）

```
走位/翻滚 → 锁定目标 → 近战连击/远程射击 → 闪避敌人攻击
    → 元素附着（火） → 造成元素伤害 → 冷却 → 继续战斗
```

| 动作 | 按键 | 手感目标 |
|:----|:----:|---------|
| 移动 | WASD | 平滑、响应快 |
| 冲刺/翻滚 | Shift / Space | 有短暂无敌帧 |
| 近战攻击 | 鼠标左键（连击） | 三段连击，每段不同动画，HitStop 感 |
| 远程射击 | 鼠标右键 | 弹丸飞行速度适中，有下坠/跟踪 |
| 锁定敌人 | 鼠标中键 | 切换锁定，视角跟随 |
| 元素技能 | Q/E | 火球/冰冻/雷击 |

### Short-Term（短循环 — 5-15分钟）

```
1. 选择地牢（最新发布 / 好友推荐 / 排行榜）
2. 进入 → 房间 1（清怪）→ 房间 2（清怪 + 机关）→ 房间 3（精英怪）→ Boss房
3. Boss 战 → 击败/死亡
4. 结算界面（评分、掉落的组件/素材、经验）
5. 返回大厅
```

### Session-Level（整局循环 — 30-60分钟）

```
登录大厅 →
    ┌─ 浏览 & 挑战（2-3局地牢，30分钟）→
    │   收获素材/经验 → 升级 → 解锁新编辑组件
    │       ↓
    └─ 打开编辑器 → 用新组件改进自己的作品（20分钟）→
        保存/发布 → 去看看有没有人评分
            ↓
   下线 —— 有明确的断点，但明天有新发布的内容等着你
```

### Long-Term Progression（长期循环 — 数天/数周）

```
冒险者等级提升 → 解锁更多编辑组件（新怪物、新机关、新装饰）
    → 创作更高质量的地牢 → 获得评分 & 声誉
        → 解锁"高级创作者"标签 → 更多权限/展示位
            → 作品被大量游玩 → 成就感 → 继续创作
```

### Retention Hooks

| Hook | Mechanism |
|:----:|-----------|
| **Curiosity** | 永远有新的地牢发布——"今天别人做了什么样的好东西？" |
| **Mastery** | 两条成长曲线：战斗技术提升 + 创作水平提升 |
| **Investment** | 花了时间做的地牢不会消失——你的作品集就是你的游戏历程档案 |
| **Social** | 异步社交——看到熟悉的名字新发布了地牢、收到点赞通知 |

## Game Pillars

本作的 4 根设计支柱——详见 `game-pillars.md`

1. **创造即游戏** — UGC 不是额外模式，创作本身就是核心玩法
2. **每一次冒险都不同** — 没有固定关卡，每一局都是全新体验
3. **有限的工具，无限的可能** — 模板化组件，但组合方式无穷
4. **故事在我手中** — 每一场地牢都在讲述一个故事

### Anti-Pillars

- **不是叙事驱动型游戏** — 故事是佐料，不是主菜
- **不是付费赢/数值深坑** — 不卖数值，卖编辑模板和装饰

## Technical Risk Register（Top 5）

| # | 风险 | 概率 | 影响 | 缓解措施 |
|:-:|:----|:---:|:----:|---------|
| 1 | **UGC 3D 编辑器开发复杂度** | 🔴 高 | 🔴 高 | MVP 只做基础放置（在 3D 视口中拖放怪物/道具保存为 JSON），不做自由切/旋转 |
| 2 | **3D 战斗手感调优** | 🟡 中 | 🟡 中 | 参考开源 Godot ARPG 模板；先用简单 Hitbox + 动画计时器，后续用 StateMachine 优化 |
| 3 | **AWS GameKit + Lambda + DynamoDB 集成** | 🟡 中 | 🟡 中 | MVP 只做最基本的上传/下载流程（Get/Put/Lists），身份认证用 GameKit SDK |
| 4 | **用 Godot 做 3D 动作游戏的性能** | 🟡 中 | 🟡 中 | MVP 场景保持小型（单房间数十个怪物），使用 Instancing + LOD |
| 5 | **单人开发精疲力尽/范围膨胀** | 🔴 高 | 🔴 高 | 严格按 MVP 定义范围，不中途加功能。每个 Milestone 完成后休息并评估再继续 |
